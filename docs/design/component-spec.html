  • Utilitiesbg-cell text-ink border-rule, text-fig font-mono, bg-cta text-cta-ink. Components are React components plus utilities, and no @apply classes except the .prose scope.
  • Resets--color-*, --text-* and --radius-*: initial come before the brand tokens, so Tailwind's defaults can't leak in (no stray blue-500 or text-[15px]). The type scale is eight steps: 12, 14, 16, 18, 20, 28, 42, 60.
  • HighlightAdd hl to the Recommended column's cells (not the action row) and to callouts. No dark: variant is needed: the scope already holds the light values.
  • GridsArbitrary grid tracks use minmax(0,…), e.g. grid-cols-[minmax(0,1fr)_minmax(0,3fr)]. A bare 1fr lets wide content push the page sideways on phones.
  • FontsPreload only Chivo, with adjustFontFallback so the 60 px hero doesn't shift when it swaps in. Chivo Mono loads with preload: false. One variable file per family.
  • DarkValues swap under prefers-color-scheme on the raw variables, so no dark: variants are needed in markup. The data-bs-theme script goes away.
  • Stripeappearance.variables reads the same values (colorPrimary, colorBackground, colorText, colorDanger, borderRadius: '2px', fontFamily Chivo), switched with matchMedia.
